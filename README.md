# LX Pantos Textile / Garment Schedule

Static homepage served at https://lxpantosfashion.co.kr (GitHub Pages).

- `index.html` — the published page (generated; don't edit by hand)
- `build/data/*.json` — one file per schedule dataset
- `build/src/` — page pieces (styles, scripts, logo, d3)
- Rebuild: `python3 build/build.py`
